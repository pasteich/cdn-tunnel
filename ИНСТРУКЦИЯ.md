# Инструкция для новичков

Пошагово: как поднять свой VPN и раздать его друзьям. Технических знаний не
требуется — нужно только уметь копировать текст и нажимать кнопки.

Если коротко: **вы разворачиваете сервер один раз, а дальше вся работа — это
выпустить ссылку `cdn://…` и отправить её человеку.**

## 1. Что это такое

Обычный VPN виден со стороны: провайдер замечает, что вы соединяетесь с чем-то
непонятным, и может это закрыть. Здесь трафик идёт **через CDN** — крупную сеть
доставки контента (Cloudflare и подобные), через которую ходит полмира. Со
стороны это выглядит как обычная загрузка сайта.

```
Ваш телефон ──TLS/HTTP2──► CDN (обычный сайт) ──► ваш сервер ──► интернет
```

Сайты будут видеть IP-адрес **вашего сервера**, а не ваш настоящий.

Одно приложение работает в двух ролях:

- **Владелец** — вы. Разворачиваете сервер, выпускаете ссылки, закрываете доступ.
- **Друг** — тот, кому вы дали ссылку. Вставляет её и нажимает «Запустить VPN».
  Больше ему ничего знать не нужно.

## 2. Что понадобится

| Что | Зачем | Сколько стоит |
|-----|-------|---------------|
| **VPS** — арендованный сервер с Linux | через него пойдёт трафик | от ~200 ₽/мес |
| **Домен** | адрес, за которым прячется сервер | от ~200 ₽/год |
| **CDN** (Cloudflare и подобные) | маскирует трафик под обычный сайт | бесплатно |
| **Android-телефон** | 8.0 и новее, 64-битный (почти все с 2017 года) | — |

Что нужно знать про VPS: его **IP-адрес**, **порт SSH** (обычно 22),
**пользователя** (обычно `root`) и **пароль**. Всё это даёт хостинг при покупке.

Что нужно сделать с доменом: привязать его к CDN и указать в настройках CDN, что
«origin» (источник) — это IP вашего VPS. Оранжевое облачко в Cloudflare должно
быть **включено**. Понадобятся два значения:

- **Host / SNI** — ваш домен, например `example.com`;
- **IP CDN** — адрес, который выдаёт CDN для этого домена. Узнать можно командой
  `ping example.com` — в ответе будет нужный IP.

> **Важно:** это должен быть IP *CDN*, а не вашего VPS. Если написать IP сервера,
> маскировка пропадёт и смысла в затее не будет.

## Шаг 1. Установить приложение

1. Скачайте `cdn-tunnel.apk` из [Releases](../../releases) на телефон.
2. Откройте файл. Android спросит разрешение на установку из неизвестных
   источников — разрешите (это обычное дело для приложений не из Play Market).
3. Запустите **CDN Tunnel**. Все поля пустые: приложение не содержит ни адресов,
   ни паролей — вы задаёте всё сами.

Внизу три вкладки: **Туннель**, **Сервер**, **Трафик**.

---

## Шаг 2. Развернуть сервер

Приложение само зайдёт на VPS по SSH и всё настроит. Ставить что-либо на сервер
руками не нужно.

Откройте вкладку **Сервер** и заполните:

| Поле | Что вписать |
|------|-------------|
| Адрес VPS | IP вашего сервера |
| SSH-порт | обычно `22` |
| Пользователь | обычно `root` |
| SSH-пароль | пароль от сервера |
| Слушать (-addr) | оставьте `:80` |
| Метод (сервер) | оставьте `both` |
| **Мастер-ключ сервера** | **оставьте пустым** — сгенерируется сам |
| Рестарт сервиса, мин | `0` (или, скажем, `40` — сервис будет сам перезапускаться) |

Нажмите **«Развернуть»**. Внизу пойдёт журнал из шести шагов: подключение,
определение архитектуры, загрузка, systemd-сервис, запуск, проверка. В конце
должно появиться:

```
✓ Сервер запущен и слушает. Выпускайте ссылки в «Управлении сервером».
```

Сервер прописан в автозапуск: после перезагрузки VPS поднимется сам.

> **Мастер-ключ** — главный секрет. Им подписываются ссылки и открывается панель
> управления. Никому его не давайте: друзьям он не нужен. Он сохраняется в
> приложении, но на всякий случай посмотрите его (значок глаза в поле) и
> запишите — понадобится, если будете настраивать приложение заново.

## Шаг 3. Подключиться самому

Вам ссылка не нужна — вы входите мастер-ключом.

1. Вкладка **Туннель** → разверните **«Ручная настройка»**.
2. Заполните: **IP CDN**, **Host/SNI** и **мастер-ключ** (тот же, что на сервере).
3. Нажмите **«Запустить VPN»**, разрешите Android создать VPN-подключение.

Через несколько секунд вверху появится зелёное **«Подключено — трафик проверен
сквозь туннель»**, а в шторке Android — значок VPN. Проверить можно так: откройте
любой сайт «узнать свой IP» — он должен показать адрес вашего сервера.

На вкладке **Трафик** видно скорость, объём, число соединений и пинг.

## Шаг 4. Позвать друга

1. Вкладка **Сервер** → **«Управление сервером»**. Откроется панель: приложение
   зайдёт на сервер по SSH и покажет его состояние.
2. Нажмите **«Новая ссылка»**. Host и IP CDN уже подставлены — впишите только
   **подпись**: кому эта ссылка («Андрею», «ноут», «маме»). Подпись видите только
   вы, она нужна, чтобы не путать ссылки.
3. Нажмите **«Выпустить»** → **«Отправить»** и выберите мессенджер. Или
   **«Скопировать»** и вставьте куда угодно.

Друг получает строку вида `cdn://AaeDLRBH9k2LT…`. Ему нужно:

1. установить тот же APK;
2. **открыть ссылку прямо из мессенджера** — приложение подхватит её само.
   Либо: скопировать ссылку → вкладка «Туннель» → **«Из буфера»** →
   **«Импортировать»**;
3. нажать **«Запустить VPN»**.

Всё. Ни пароля, ни адресов, ни настроек другу вводить не нужно — они зашифрованы
внутри ссылки.

> **Ссылка привязывается к первому телефону**, который по ней подключился. Со
> второго она уже не откроется — это защита от того, что ссылку перешлют дальше.
> Нужен другой телефон — нажмите «Отвязать» в панели.

## Управление доступом

Вся суть системы в одном предложении: **доступ к серверу дают только ссылки из
панели**. Сколько ссылок выпущено — столько людей и может подключиться. Нет
никаких «пользователей», лимитов и паролей для друзей: одна ссылка = один человек
= одно устройство.

Каждая ссылка в панели показывает своё состояние:

| Состояние | Значит |
|-----------|--------|
| **на линии** | человек подключён прямо сейчас (видны его адрес и сколько он на связи) |
| **привязана** | ссылкой пользовались, сейчас человек офлайн |
| **не использована** | вы её выпустили, но ещё никто не подключался |
| **отозвана** | доступ закрыт, но запись и счётчики целы |

И пять кнопок:

| Кнопка | Что делает | Обратимо? |
|--------|-----------|-----------|
| **Поделиться** | собирает ссылку заново и отправляет — если потеряли исходную | — |
| **Сбросить** | снимает человека с линии; он переподключится через пару секунд | — |
| **Отвязать** | забывает устройство: ссылку можно открыть на другом телефоне | да |
| **Отозвать** | закрывает доступ, счётчики трафика остаются | да, кнопкой «Вернуть» |
| **Удалить** | стирает запись — **доступ закрывается навсегда** | **нет** |

Разница между «Отозвать» и «Удалить» важная:

- **Отозвать** — временно. Человек получит отказ, но вы в любой момент вернёте
  доступ той же ссылкой.
- **Удалить** — окончательно. Эта ссылка мертва навсегда, даже если человек
  попробует переподключиться. Придётся выпускать новую.

В обоих случаях, если человек **сидел онлайн**, его VPN погаснет сам в течение
15 секунд — приложение на его телефоне увидит отказ и выключит туннель.

Чтобы переименовать ссылку, нажмите на её подпись в панели.

## Что видит друг, а что только вы

| | Друг | Вы (владелец) |
|---|---|---|
| Подключиться по своей ссылке | да | да (и без ссылки, по ключу) |
| Свой трафик и скорость | да | да |
| Чужие ссылки, их трафик и адреса | **нет** | да |
| Выпускать и закрывать ссылки | **нет** | да |
| Панель управления сервером | **нет** | да |
| Мастер-ключ | **нет** | да |

Панель открывается только мастер-ключом — ссылкой в неё не войти, даже рабочей.

## Если что-то не работает

### Сообщения в приложении

| Что пишет | Что случилось | Что делать |
|-----------|---------------|------------|
| **Ссылки больше нет** | владелец удалил эту ссылку | попросить новую |
| **Ссылка отозвана** | владелец временно закрыл доступ | попросить вернуть |
| **Ссылка занята** | ссылка уже привязана к другому телефону | попросить нажать «Отвязать» или выдать новую |
| **Ссылка не принята** | ссылка от другого сервера или сервер переразвёрнут с новым ключом | нужна новая ссылка |
| **Неверный ключ** | мастер-ключ в приложении не совпадает с серверным | сверьте ключ на вкладке «Сервер» |
| **Нет маршрута** | туннель поднялся, но трафик не идёт | проверьте, что CDN включён для домена (оранжевое облачко) |
| **Ошибка** | сервер недоступен | вкладка «Сервер» → «Статус» |

### Типовые ситуации

**«Развернуть» не проходит.** Проверьте IP, порт и пароль SSH. Если хостинг
запрещает вход по паролю для `root` — включите его или заведите вход по ключу.

**Развернулось, но VPN не подключается.** Скорее всего дело в CDN:

1. проверьте, что в поле IP CDN стоит адрес *CDN*, а не VPS (`ping ваш-домен`);
2. в Cloudflare должно быть оранжевое облачко (проксирование включено);
3. в настройках CDN origin должен указывать на IP вашего VPS по **HTTP, порт 80**.

**Скорость низкая или пинг большой.** Вкладка «Туннель» → «Ручная настройка» →
**Транспорт**: попробуйте `stream` вместо `chunked`. Если CDN его не пропускает,
приложение само вернётся на `chunked` (будет видно в журнале).

**Сервер обновился, а приложение ругается на версию.** Откройте «Управление
сервером» и нажмите **«Обновить сервер»** — приложение зальёт свежий бинарь.

**Ничего не помогает.** Вкладка «Трафик» → журнал внизу: там видно каждый шаг
подключения. Если непонятно — покажите журнал тому, кто вам дал ссылку.

## Частые вопросы

**Сколько человек можно подключить?**
Сколько ссылок выпустите. Ограничения нет — упрётесь только в канал сервера.

**Друг может раздать мою ссылку дальше?**
Может попробовать, но ссылка привяжется к первому телефону, и у остальных будет
«Ссылка занята». Увидите это в панели и сможете закрыть доступ.

**Что если я потерял ссылку, которую выдал?**
Нажмите «Поделиться» на нужной строке в панели — ссылка соберётся заново.

**Друг видит мой мастер-ключ?**
Нет. Внутри ссылки лежит отдельное удостоверение, подписанное ключом, но не сам
ключ. По ссылке нельзя ни открыть панель, ни выпустить другие ссылки.

**Данные шифруются?**
Участок «телефон → CDN» защищён TLS. Дальше, от CDN до вашего сервера, идёт
обычный HTTP — это требование схемы маскировки. Для сайтов по HTTPS (а это
почти всё сегодня) ваше соединение с сайтом всё равно зашифровано из конца в
конец, CDN видит только поток байтов.

**Что останется на сервере?**
Реестр ссылок и счётчики трафика — файл `/var/lib/cdn-tunnel/links.json`. Журналы
посещённых сайтов сервер не ведёт.

**Как удалить всё с сервера?**
Вкладка «Сервер» → **«Удалить с сервера»**: снимет сервис и бинарь.

**Как стереть настройки с телефона?**
Вкладка «Туннель» → «Ручная настройка» → **«Стереть все настройки»**.
